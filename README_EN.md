# legado (阅读)

An open-source Material Design 3 reader built with Flutter. Shows "legado" on non-Chinese systems and "阅读" when the system language is Chinese.

## Features

- **Local books**: TXT / EPUB / PDF import & reading, chapter word count
- **Online sources**: JS-rule based search, TOC & content; compatible with the legado source ecosystem
- **Reading**: theme manager, fine-grained typography, TTS read-aloud, bookmarks, reading stats
- **Bookshelf & discovery**: groups, customizable home modules, RSS reading
- **Extras**: backup & restore, web service, `legado://` deep links, QR sharing, theme import/export

## Download

Grab the latest APK (universal / arm64) from [Releases](https://github.com/ReTyne/legado-Klys/releases).

Current version: **1.0-beta**

## Development

```bash
flutter pub get
flutter run
flutter test        # 83 tests
```

Launcher icons are generated by `tools/gen_launcher_icons.py`; run `python3 tools/gen_launcher_icons.py` after changing the design.
